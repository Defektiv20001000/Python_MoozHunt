<h1 align="center">MoozHunt 🎵</h1>

<p align="center">
  Локальный музыкальный плеер на Python с поддержкой плейлистов, загрузкой треков и ИИ-анализом аудио.
</p>

---

## ✨ Основные возможности

* **Воспроизведение музыки:** удобный плеер с управлением треками (`player.py`).
* **ИИ-анализатор аудио:** определение характеристик и фильтрация композиций с помощью нейросети CLAP (`AIAnalyzer.py`).
* **Управление плейлистами:** создание и редактирование собственных подборок (`Playlists.py`).
* **Загрузка треков:** встроенный модуль скачивания музыки (`Download.py`).
* **Локальная база данных:** хранение библиотеки треков и метаданных (`DataBase.py`).
* **Кастомизация интерфейса:** поддержка тем оформления (`theme.py`, `dialogs.py`).

---

## 🛠 Установка и запуск

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/Defektiv20001000/Python_MoozHunt
cd Python_MoozHunt
```

### 2. Установите зависимости Python
Убедитесь, что у вас установлен Python 3.9+, и установите необходимые библиотеки (например, PyQt/Tkinter, torch, transformers, mutagen и др. — в зависимости от ваших импортов):
```bash
pip install -r requirements.txt
```

### 3. Добавьте внешние компоненты (важно!)
Из-за ограничений GitHub на размер файлов тяжелые бинарники и веса нейросети не включены в репозиторий. Перед запуском добавьте их в корень проекта:

1. **FFmpeg:** скачайте сборку для вашей ОС с [официального сайта](https://ffmpeg.org) и поместите файлы `ffmpeg.exe` и `ffprobe.exe` в корневую папку проекта.
2. **Модель CLAP-AI:** скачайте веса модели (например, `laion/clap-htsat-unfused` с [Hugging Face](https://huggingface.co)) и распакуйте их в папку `clap-ai/` в корне проекта.

### 4. Запустите приложение
```bash
python Application.py
```

## 📁 Структура проекта

* `Application.py` — главный файл запуска и интерфейс приложения.
* `player.py` — логика аудиоплеера.
* `AIAnalyzer.py` — модуль анализа треков с помощью ИИ.
* `Playlists.py` — работа с плейлистами.
* `Download.py` — загрузка аудиофайлов.
* `DataBase.py` — работа с локальной базой данных SQLite (`music_vault.db`).
* `dialogs.py` / `theme.py` — диалоговые окна и стили оформления.
